# 隐私政策（开源版）

最后更新：2026-05-09

## 1. 数据收集范围

本项目开源版默认仅处理实现功能所需的最小数据，包括：

- 用户账号信息（如邮箱）
- 实例配置数据（如用户填写的 WSS 地址）
- 运行日志（用于故障排查）

## 2. 数据用途

收集的数据仅用于：

- 用户认证与账户管理
- MCP 服务实例运行与状态管理
- 安全审计与问题排查

## 3. 数据存储

- 业务数据默认存储在部署方的 MySQL 实例中。
- 如启用报告 Worker，相关向量/报告数据可能存储于 PostgreSQL。

## 4. 第三方服务

当你配置第三方 API Key（如搜索、航班、邮件服务）时，调用行为受对应第三方服务条款约束。

## 5. 开源说明

本仓库为开源项目。部署者需自行承担生产环境中的数据合规责任（包括但不限于告知、授权、留存策略和删除策略）。
