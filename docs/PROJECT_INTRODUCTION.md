# 项目介绍

`xiaozhi-esp32-mcp` 是一个面向小智设备生态的 MCP 服务管理平台。

## 核心能力

- 服务市场：统一管理可接入 MCP 服务
- 实例管理：创建、启动、停止、删除实例
- 账号体系：注册/登录、邀请码、有效期与激活码
- 管理后台：用户与激活码管理

## 开源版说明

- 开源版聚焦 MCP 管理核心能力
- 知识库相关模块已移除，不在开源版范围内
